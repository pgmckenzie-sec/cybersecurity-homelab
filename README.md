# Cybersecurity Homelab

## Overview

This lab was built to gain hands-on experience with:

- Active Directory
- Windows Server 2019
- Wazuh
- Splunk
- Kali Linux

## Network Layout

| System | IP Address | Role |
|----------|-------------|----------|
| Windows Server 2019 | 192.168.56.10 | Domain Controller |
| Ubuntu | 192.168.56.50 | Splunk |
| Kali Linux | 192.168.56.x | Attack Machine |

## Projects Completed

### Active Directory
- Created domain users
- Created HR and IT shares
- Joined workstation to domain

### Wazuh
- Installed Wazuh agent
- Connected agent to manager

### Splunk
- Installed Splunk on Ubuntu
- Configured Windows log forwarding
